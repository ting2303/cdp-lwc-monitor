## 重要更正:手動壓力幾乎不影響主要的 LWC-300

用資料驗證 `LWC-AveragedDAP = (TotalPower − DAP-Averaged) ÷ W`,誤差中位數約 0.00001 g/m³。

- `W` 約等於 0.095 × 流速(7 m/s 時 0.664、8 m/s 時 0.748、8.45 m/s 時 0.788)。所以 LWC-300 和手動流速成反比。
- `DAP-Averaged` 是量到的乾空氣功率,不用手動壓力。手動壓力和溫度進的是 `DAP-Calculated`。

之前面板寫「差 50 hPa,LWC-300 約差若干 g/m³」,那只適用於 `LWC-CalculatedDAP`,已經改掉。

## 校正做不到的事

- **校正沒有讓 LWC-300 和 CDP 變得更一致。** 主要成果是清掉假訊號,以及讓不同天比較公平。相關仍然只有約 0.2。
- 負值變多是預期的:移除正偏移後,低 LWC 時的雜訊會圍繞接近 0 的值。單分鐘的值(包含負值)不要單獨解讀,請看平均。
- CDP 的粒徑只能靠玻璃珠校正,不能從觀測資料自己算。
- 起霧時的 CDP 資料無法還原。
- 沒有實際風速,就無法判斷 CDP 或 LWC-300 的流速哪個對;兩者都和濃度或 LWC 成反比,影響可達 1.43 倍。
- 基線是用無雲時段外推到雲中,假設乾空氣功率在短時間內變化不大,仍是估計。
